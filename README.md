# Distributori Convenienti — V4

Versione integrata:
- massimo 5 distributori, ordinati per prezzo;
- marker automobile e distributore più grandi;
- mappa pulita: nessuna etichetta/popup sopra la mappa;
- viene mostrato un solo distributore alla volta;
- inizialmente il marker è sul distributore più vicino tra i 5 risultati;
- cliccando una riga, il marker passa al relativo distributore;
- cliccando il marker distributore si apre direttamente l'itinerario Google Maps;
- posizione veicolo mostrata come indirizzo + data/ora;
- prezzo e data "Aggiornamento MIMIT" seguono la logica di Consulta prezzi MIMIT:
  comunicazione del giorno se presente, altrimenti ultimo prezzo precedente valido.
