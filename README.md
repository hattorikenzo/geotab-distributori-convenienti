# Distributori Convenienti — V6

Novità V6:
- vengono mostrati esclusivamente prezzi dal blocco `corrente` MIMIT;
- un prezzo è valido per massimo 48 ore dalla `dtComu`;
- se `corrente` manca o supera 48 ore, l'impianto viene escluso;
- nessun fallback allo storico per la classifica dei distributori convenienti;
- il filtro viene applicato prima della selezione dei 5 più convenienti.

Restano tutte le funzioni V5/V4: raggio 5 km, massimo 5 risultati, marker veicolo/distributore, selezione riga e itinerario Google Maps.
